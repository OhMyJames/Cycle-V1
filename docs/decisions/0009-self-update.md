# 0009 应用自己更新自己

状态:已接受

## 背景

Release 里已有每个平台的压缩包和清单(大小、SHA-256)。要让安装好的应用自己发现并换上新版本,而不依赖 Electron 的更新框架(Squirrel.Mac 要求签名,而我们现在发布的是没有 Developer ID 的包)。

## 决定

- 自己写,约 400 行,所有外部依赖注入,门禁里测;真实的包在 macOS runner 上端到端测。
- 读 GitHub 发布列表而不是 `/releases/latest`(后者不含 pre-release),用 ETag 条件请求,每分钟检查不会耗尽未登录的限额。
- 由用户确认才安装。后台检查失败不打扰。
- 换包由应用退出后的小脚本完成,不在运行中的进程里替换自己的包。换之前先停掉本机 daemon。
- 完整性靠 HTTPS + SHA-256 + 大小;有签名时再要求同一个团队。没签名时无法证明来源,这是已知的缺口,等签名后补上。

## 没做

- 远端 daemon 的升级(应用不能替用户在别的机器上装东西);之后可以让客户端发现版本落后并给出命令。
- 增量更新、回滚到旧版本、更新通道(stable/beta)。
