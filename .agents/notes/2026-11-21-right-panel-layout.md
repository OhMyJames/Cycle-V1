# Agent Note: 右侧面板挤压对话区，标签按会话记住

Status: accepted
Date: 2026-11-21
Basis: 2026-11-21 负责人在 CYCL-52 中让 CYCL-89 先起草，并逐条选定（挤压、按会话记住、双击折叠、`⌘\`）；[右侧面板范围笔记](2026-11-19-right-panel-scope.md)把结构留给 CYCL-89。

## Problem

右侧面板（Overview、Files、Diff、Terminal、Browser）和对话区同时显示。CYCL-66 要做的分栏、分隔条和标签页，取决于几件还没定的事：面板放在哪、窗口窄时让谁、记住什么、以什么为范围、怎么用键盘开关，以及同一种标签能不能开几个。对话区是用户盯着 agent 干活的地方，面板只是旁边的参考：这几件事都要以"不挡住正在看的对话"为准。

## Decision

**位置与关系。** 面板是窗口的第三栏，在对话区右边，和侧栏在同一个分栏组里（ui-sdk `Resizable`）。默认关闭。打开时挤压对话区，不覆盖它：面板是拿来对照着对话看的（agent 改了什么、终端里跑着什么），盖住对话就失去了意义。

**宽度。** 默认 400px，最小 280px，最大为窗口宽度减去对话区的最小宽度。对话区最小 400px（原来是 480px）。窗口变窄时依次让出：先把面板压到最小，再自动折叠侧栏（窗口变宽后恢复成用户原来的状态，不算用户的操作，不记住），最后才把对话区压到最小。最小窗口 720px 时，对话区 400px 加面板 280px 加两条分隔条正好放下，所以任何窗口宽度都不需要覆盖模式。

**分隔条。** 两条分隔条行为相同，都用 ui-sdk 的：拖动、方向键（Shift 加大步长）、Home/End、Enter 和双击折叠再恢复。CYCL-66 票上写的"双击复位"不做：它和 SDK 的"双击折叠"冲突，侧栏已经是折叠，同一个窗口里两条分隔条双击效果不同会让人困惑。恢复到默认宽度没有专门的动作。

**折叠与开关。** 面板折叠就是关闭：内容卸载，不占资源（CYCL-90）。主区头部右上角加一个只有图标的按钮（`Tip`："Show panel"/"Hide panel"），和左上角侧栏按钮对称。快捷键 `⌘\`（其他平台 `Ctrl+\`）开关面板；有模态框时让位。把面板拖到小于最小宽度的一半也会关闭它，和侧栏一样。

**记住什么、按什么范围。** 每个会话有自己的一套面板状态：开没开、打开了哪些标签、当前是哪个。切换会话时面板换成那个会话的样子；没打开过面板的会话默认关闭。这样每个会话的面板就是为那件事摆好的（这个会话看 Diff，那个会话开着终端），回到它时不用重新摆。状态存在 `localStorage`，按 `(environmentId, sessionId)` 记，重启后恢复，只保留最近用过的 200 个会话；删除会话时一并删掉。**宽度**按窗口记，不按会话：所有会话共用一个宽度，切换会话时只有开关和标签变，面板不会忽宽忽窄（用侧栏同一个 `autoSaveId`；SDK 按面板组合分别存布局，所以开关面板不会弄乱侧栏宽度）。

**标签。** v1 有五种：Overview、Files、Diff、Terminal、Browser。Overview、Files、Diff 是当前会话的视图，每种最多一个。Terminal 和 Browser 是有自己状态的实例（一个 shell、一个页面），可以各开几个；它们属于哪个 workspace、切换会话时怎样显示，由 CYCL-96 和 CYCL-99 决定，面板只负责能放多个同类标签。标签条高 42px，和对话区头部对齐；标签用 ui-sdk `Tabs`，方向键切换，只有当前标签的内容挂载。

**没有打开的会话时**（新建会话页、空状态），面板关闭；发出第一条消息、会话建好后，它从关闭开始。

## Alternatives considered

- **窄窗口时覆盖对话区**（面板从右边滑出、盖在对话上）：能让对话区保持宽，但盖住的正是面板要对照的内容，还要多一种呈现方式和对应的测试。上面的让出顺序在最小窗口下也放得下，就不需要它。
- **按窗口记住，标签内容跟着会话换**（起草时的建议）：切换会话时面板样子不变，只换内容。负责人选了按会话记住：不同会话要看的东西不同，面板应该是为那个会话摆好的。
- **快捷键 `⌘⌥B`**（起草时的建议，和侧栏 `⌘B` 成对）：负责人选了 `⌘\`。
- **双击分隔条复位到默认宽度**：见上，和 SDK 及侧栏的行为冲突。

## Consequences

- CYCL-66 的约束：分栏是 ui-sdk `Resizable`，三栏同组；面板和侧栏都按像素设上下限；对话区最小 400px；需要"自动折叠侧栏再恢复"的逻辑（SDK 没有，要自己按窗口宽度判断）；标签页用 ui-sdk `Tabs` 套 Cycle 样式。
- 对话区最小宽度从 480px 降到 400px：输入框的工具条在 400px 下要再检查一次（DESIGN.md 附录 E 已有"720×480 下 `composer-toolbar` 适配"一项）。
- `⌘\` 是新的全局快捷键，要写进 DESIGN.md §5.4 和应用菜单。
- 按会话记住要一份小的持久状态（每个会话几个标签 id），和草稿一样按环境加会话为键；切换会话时面板开关会让对话区宽度变化，这是选择按会话记住的代价。
- 还没验证：最小宽度下真实的对话和 overview 内容是否够看。CYCL-66 用画廊在 720×480 和 1200×800 两种尺寸截图验证，有问题再回来改这份笔记。
