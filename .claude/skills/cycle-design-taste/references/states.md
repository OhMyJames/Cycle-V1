# 状态

一块界面只画了"正常"就没有做完。下面每块都要有这些状态的画面,并在 DOM 测试里各有一条(`packages/ui/test/dom/app.dom.tsx`)。

通用的六种:**空**、**加载**、**出错**、**断线或重连**、**内容很长**、**数量很多**。

## 逐块

| 块 | 要看的状态 |
|---|---|
| 主机栏(host-bar) | 已连接、连接中、重连中、连不上(带远端原话)、没有主机、主机名很长 |
| 会话列表(sidebar) | 空、几百个、标题很长、标题为空、正在工作、等待批准、已归档、刚删除 |
| 对话(conversation) | 空、加载历史、很长的历史、流式中、被取消、出错结束、断线中、只有思考没有回答 |
| 消息 | 很长的单词或路径、宽表格、超长代码行、很多列表项、不安全的链接和图片(已有拦截说明) |
| 工具卡(tool) | 进行中、完成、失败、输入很长、输出很长、没有输出、被拒绝 |
| 权限卡(permission) | 一个请求、同时多个、命令很长、在别处已被回答(应自动关闭)、重连后重新询问 |
| 计划(plan) | 没有、全部待办、部分完成、全部完成、条目很长 |
| 输入框(composer) | 空、多行、很长、发送中、断线、被禁用时要说明原因 |
| 对话框(dialogs) | 打开、校验出错、提交中、提交失败(带原因)、Esc 与点遮罩的行为、焦点回到触发处 |
| 更新(update) | 没有更新、检查中、可用、下载中、安装中、失败(带原因)、已禁用 |
| 设置表单(config-form) | 没有可设置项、很多项、值来自 agent 而非索引(现在不会回显,是已知缺口) |

## 出错的画法

- 出错的位置是出错的地方:主机连不上,错误显示在主机栏和空状态里,不是弹一个别处的提示。
- 原因用原话,等宽,可选中,长了换行;旁边有明确的下一步(Retry、Edit host、Check…)。
- 不要把错误只放在会消失的提示里:用户错过了就再也看不到。

## 极端数据

做完先用极端数据看一遍:一个 200 字符的标题、一个 500 字符没有空格的路径、一个 3000 行的输出、一个 800 个会话。
布局要么省略(并能看全),要么换行或滚动,不能撑破侧栏或让整个页面出现横向滚动条。
